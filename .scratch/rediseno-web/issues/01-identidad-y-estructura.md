# 01: Identidad visual y estructura compartida

**Objetivo / Qué construir:** definir una identidad temporal para el taller y una estructura de navegación y estilos coherente para las pantallas de la aplicación.

**Status:** spec-ready

**Referencia:** [Especificación del rediseño web](../spec.md), alcance y criterios 1–3.

## Alcance

- Fondo claro, navegación azul oscuro, acentos naranja y tipografía legible.
- Identidad ficticia centralizada para su reemplazo cuando se reciban los datos reales.
- Componentes compartidos para navegación, acciones, estados, formularios, errores y contenido.
- Reglas responsive y accesibilidad básica.

## Criterios de aceptación

- [ ] Las cuatro pantallas usan una misma estructura y sistema visual.
- [ ] La identidad ficticia es uniforme y su reemplazo no requiere reescribir cada pantalla por separado.
- [ ] Texto, controles, estados y foco tienen contraste y legibilidad adecuados.
- [ ] A 320px de ancho no aparece desplazamiento horizontal de página.

## Límites

No incluye diseño de `/admin/` ni documentos PDF.
